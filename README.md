# Sales MIS Dashboard — Excel

## Project Overview
A Sales Management Information System (MIS) dashboard built using Microsoft Excel and Power Query to analyze sales performance from April 2018 to March 2019.

## Tools Used
- Microsoft Excel
- Power Query
- Excel formulas and charts

## Key Features
- Cleaned and merged sales datasets using Power Query
- Monthly sales, profit and quantity summaries
- Category-wise sales analysis
- Actual sales versus target comparison
- KPI cards for Total Sales, Total Profit, Total Quantity Sold and Target Achievement
